# 🖼️ BatchPixel - 브라우저 기반 일괄 이미지 리사이저

별도의 빌드 도구나 복잡한 설치 없이, **순수 HTML, CSS, JavaScript**로 동작하는 고성능 일괄 이미지 리사이징 웹 애플리케이션입니다.

---

## 🔒 100% 클라이언트 사이드 (데이터 보안 보장)
- 사용자가 업로드한 모든 이미지는 **사용자 PC의 브라우저 메모리(HTML5 Canvas API)** 내에서만 연산됩니다.
- 외부 서버나 클라우드로 **단 1바이트의 데이터도 전송되지 않으며**, 인터넷 연결이 끊긴 오프라인 환경에서도 안전하게 사용할 수 있습니다.

---

## ✨ 핵심 기능

### 1. 5가지 리사이징 기준 완벽 지원
1. **X축 기준 (너비 Width)**: 목표 가로폭(px)을 기준으로 원본 종횡비를 유지하며 세로 높이 자동 계산
2. **Y축 기준 (높이 Height)**: 목표 세로높이(px)를 기준으로 원본 종횡비를 유지하며 가로 너비 자동 계산
3. **긴축 기준 (Longest Edge)**: 이미지의 가로/세로 중 더 긴 쪽을 지정 픽셀에 맞추고, 짧은 쪽은 비례 축소/확대
4. **짧은축 기준 (Shortest Edge)**: 이미지의 가로/세로 중 더 짧은 쪽을 지정 픽셀에 맞추고, 긴 쪽은 비례 축소/확대
5. **퍼센트 비율 기준 (Percentage %)**: 1% ~ 500% 슬라이더 및 직접 입력으로 원본 대비 비율 조절

### 2. 출력 포맷 & 품질 제어
- **출력 포맷 선택**: 원본 포맷 유지 (Keep Original), JPG, PNG (무손실/투명 지원), WEBP
- **압축 품질 조절**: 슬라이더로 10% ~ 100% 화질 및 용량 최적화 조절

### 3. 다운로드 옵션
- **개별 다운로드**: 각 이미지 카드의 [개별 다운로드] 버튼으로 원하는 이미지만 즉시 저장
- **일괄 다운로드 (.ZIP)**: JSZip 엔진을 통해 여러 장의 이미지를 브라우저에서 즉시 압축하여 단일 `.zip` 파일로 저장 (실시간 프로그레스 바 제공)

## 🚀 실행 방법

### 방법 1 (가장 간편한 방법)
폴더 내 **`run.bat`** 파일을 더블클릭하거나, **`index.html`** 파일을 더블클릭하여 웹 브라우저(크롬, 엣지, 웨일 등)로 바로 실행합니다.

### 방법 2 (로컬 웹서버 실행)
현재 폴더에서 터미널을 열고 다음 명령어 실행:
```bash
python -m http.server 8089
```
이후 브라우저에서 `http://localhost:8089` 로 접속합니다.

## 📁 파일 구조
- `index.html`: 애플리케이션 구조 및 컨트롤 UI
- `style.css`: 모던 다크 글래스모피즘 테마 및 반응형 디자인
- `app.js`: 5가지 리사이징 계산 엔진, Canvas 처리, 다운로드 및 JSZip 압축 파이프라인
- `jszip.min.js`: 오프라인 환경 지원을 위한 클라이언트 ZIP 라이브러리
- `run.bat`: 원클릭 실행 배치 파일
- `test_samples/`: 가로형, 세로형, 정사각형 테스트용 샘플 이미지
